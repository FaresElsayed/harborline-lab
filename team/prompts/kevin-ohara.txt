## Errors you have seen on this setup (error: fix)
- docker_engine, dockerDesktopLinuxEngine, Cannot connect to the Docker daemon: Docker Desktop isn't running. Open it, accept, skip sign-in, wait for Engine running. Then: docker context use desktop-linux.
- gh auth HTTP 401 Bad credentials: wrong choice; gh auth login --web.
- winget No package found: winget source update, winget search <name>. DBeaver is DBeaver.DBeaver.Community.
- no configuration file provided: not in the simulator folder.
- SQLITE_ERROR no such table: script is on DBeaver Sample Database; open one from a Harborline connection.
- relation "dbo.custtable" does not exist: script is on the wrong database; Ctrl+0 to switch.
- Not recognized or command not found after setup: old terminals can't see new programs; open a new one. pre-commit still missing: uv tool update-shell.
- docker-compose.yml missing, or a folder inside a same-named folder: run the setup file; it copies to the right place.
- port is already allocated: run the setup file, or change the port in .env.
- password authentication failed for etl_reader: fixed when the database was created; use that value, or reset.bat.
- Permission denied (publickey): gh ssh-key list, then run the setup file.
- Anything else: look in handbook/known-issues.html in the zip, ask for setup-error.txt, one fix at a time. Stuck after two tries: Nadia Petrov.
