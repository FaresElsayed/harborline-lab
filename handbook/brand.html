Brand kit and dashboard style guide

Every dashboard you ship is a Harborline document. This kit makes the fifteen of them look like they come from one company: the logo and colours, a data-viz palette that colour-blind readers can use, two typefaces that keep numbers aligned, a page grid with ready-made backgrounds per department, and themes for Power BI, Streamlit, Databricks AI/BI and Snowsight.

Set up in fifteen minutes

Do these once on your Windows machine. The details for each are further down this page.

Logo

Two pier posts and the waterline between them: the harbor, and the line that moves goods through it. The posts make an H; the orange waterline is the only warm colour in the identity, so it is the first thing you see on a navy header.

Clear space and size

  • Keep a clear space of one quarter of the mark's height on every side (12 px around a 48 px lockup).
  • Smallest sizes on screen: lockup 120 px wide, mark 16 px (use favicon.svg below 24 px; its waterline is drawn thicker).
  • Use the light files on white, Fog or Sand, the dark files on navy or the dark theme, and mono for single-colour print, embossing and fax.

Don't

  • Recolour the waterline, the posts or the wordmark, or put the light lockup on a photograph.
  • Stretch, rotate, outline, shadow or add a gradient to any part of the logo.
  • Retype the wordmark in a font. The letters are drawn, not typed; use the files.
  • Put another logo inside the header band. Client logos go in the title area as text, never beside the mark.

Colour

Navy carries the brand, teal is the one interactive accent, and Signal Orange is rationed: under five percent of any screen. Interface colours come in a light and a dark step; use the token names in code and the hex values in tools that cannot read tokens. Click Copy next to any value.

Data-viz palettes

Every chart colour has one job: categorical says which thing, sequential says how much, diverging says which side of a reference, and status says good or bad. The palettes below were computed, not picked: each was run through the colour-blind and contrast validator in light and dark (full report).

Categorical: eight slots in a fixed order

Why the order matters

Neighbouring slots are at least 12.0 apart for protanopia and deuteranopia in light mode and 11.9 in dark (OKLab ΔE, target 8), and 23.1 / 20.0 apart for full-colour vision (floor 15). The first three slots also pass when every pair can touch, which is why scatter plots and maps get three colours at most. Slot 4 Brass is 2.2:1 on white: when you use it, show data labels or a table view.

Rules

  • Assign slots 1, 2, 3… in order and never cycle. A ninth series goes into Other (--hl-viz-other) or into small multiples.
  • Colour follows the entity, not its rank: once ATL1 is slot 1 it is slot 1 on every page, even when a filter hides DFW1.
  • A single series takes slot 1 and needs no legend; the title names it. Two or more series always get a legend, and up to four are labelled at the line end.
  • Values, labels and legends use ink colours, never the series colour.
  • When a series means good or bad (SLA met / missed), it uses the status colours instead, and the chart uses no categorical colours.

Install the fonts on Windows

  1. Open each family on Google Fonts and choose Get font → Download all: Hanken Grotesk, Archivo Narrow, JetBrains Mono.
  2. Unzip all three into one folder, for example Downloads\harborline-fonts.
  3. Open each static folder, select every .ttf, right-click and choose Install for all users (on Windows 11, Show more options first). Use the static files: each weight registers under its own name, such as Hanken Grotesk SemiBold, which is the name the themes use.
  4. Close and reopen Power BI Desktop, VS Code and your browser.

Without admin rights, this PowerShell 7 script installs them for your user only:

# PowerShell 7, no admin needed: installs the static fonts for your Windows user only.
# Assumes the three Google Fonts zips were unzipped into Downloads\harborline-fonts.
$src = "$env:USERPROFILE\Downloads\harborline-fonts"
$dst = "$env:LOCALAPPDATA\Microsoft\Windows\Fonts"
$reg = "HKCU:\Software\Microsoft\Windows NT\CurrentVersion\Fonts"
New-Item -ItemType Directory -Force $dst | Out-Null
$files = Get-ChildItem $src -Recurse -Filter *.ttf |
  Where-Object { $_.DirectoryName -like "*static*" }
foreach ($f in $files) {
  $target = Join-Path $dst $f.Name
  Copy-Item $f.FullName $target -Force
  New-ItemProperty -Path $reg -Name "$($f.BaseName) (TrueType)" `
    -Value $target -PropertyType String -Force | Out-Null
}
"Installed $($files.Count) font files"   # expect about 40

Power BI sizes are points: 1 pt is 1.33 px on the 1280 × 720 canvas. Static fonts install one family per weight, which is why the semibold weights have their own names. Viewers in the Power BI service who do not have the fonts see Segoe UI, which the theme lists as the fallback.

KPI tiles

A tile answers four questions: how much, compared with what, over which period, and which way it is going.

  • One number per tile, most important first (left). The dashboard spec sets how many tiles a page has: the grid fits five, and six to eight share the same row as narrower tiles. Never add a second row of tiles.
  • The label names the measure and the period: “OTIF, last 7 days”, not “OTIF”.
  • The comparison is a target, a budget or the prior period, written in words: “2.9 pp below target 95.0%”.
  • Arrow shows direction; colour shows good or bad. A falling dock-to-stock time is a down arrow in green.
  • Never colour the whole tile, and never use a gauge. In Power BI use the new Card visual (the theme styles it) or the KPI visual.
  • Where two departments define a KPI differently (on-time for Operations, Client Success and Finance), the tile tooltip says whose definition it uses.

Use a background in Power BI

  1. Format page → Canvas settings: keep 16:9 (1280 × 720), or choose Custom 1920 × 1080 and use the 1920 PNG.
  2. Canvas background → Image → Browse: pick the department PNG. Image fit Fit, transparency 0%.
  3. Wallpaper: colour #F3F5F7 (light) or #08131F (dark).
  4. Type the page title in a text box over the title area (white, 16 pt Archivo Narrow SemiBold); put a card bound to the load timestamp in the footer slot.
  5. Place visuals with Format → General → Properties → Size and position using the numbers above. The theme gives each visual the same white card, border and radius as the background, so a visual placed exactly on its zone looks drawn into the page. For a free layout, use the Open background.
  6. To line visuals up by eye, temporarily use the alignment overlay as the background.

Number and date formats

  • $ means USD and nothing else. Every other currency shows its ISO code (CAD, MXN, EUR, GBP).
  • Company reporting currency is USD, converted at the AX month-end rate (exchangerate table). Say so in the subtitle or tooltip.
  • Client-facing views (portal, invoices, revenue assurance per client) show the client's billing currency.
  • Tiles abbreviate (1.28M); tables show full numbers with thousands separators.
  • Negative numbers use a minus sign; Finance statements (P&L, AR) use parentheses.
  • Rates have one decimal (96.4%); shares in charts have none (34%); changes in a rate are percentage points (pp).
  • Every timestamp carries its time zone. Operations views use warehouse local time, platform views use UTC, executive views use ET (head office).

Choosing a chart

Start from the question the stakeholder asked, not from the chart gallery. Sometimes the answer is a number or a table.

The questionUseAvoid
How much, right now?KPI tile (number + comparison + period)Gauge, dial, big number with no reference
How is it trending?Line (≤ 4 series, direct-labelled); columns for ≤ 24 discrete periodsArea stacks for trends, smoothed lines, dual axis
Which is biggest / smallest?Horizontal bar, sorted, one colour; top N + OtherPie or donut with more than 3 parts, unsorted bars
What is it made of?100% stacked bar (≤ 5 parts) or a sorted bar of sharesPie, treemap for fewer than 10 items, 3D anything
Against target or budget?Bullet bar, dot plot with a target line, diverging bar (blue below, orange above)Red-green colouring, bars that do not start at zero
How do two measures relate?Scatter, first 3 colour slots only, labelled outliersTwo measures on two y-axes
How is it distributed?Histogram, box plot, strip plot of durationsAverage alone for skewed durations (show median and p90)
Where?Filled map on the sequential ramp; warehouses as labelled pointsRainbow choropleth, bubble maps with overlapping bubbles
What moved the number?Waterfall (P&L bridge, OTIF misses by reason)Stacked columns read as a bridge
Which records need action?Table or matrix, ≤ 7 visible columns, conditional formatting on one measureEvery column colour-scaled, 20-column exports on a page
Is it within limits? (cold chain, live ops)Line with the allowed band shaded, excursions marked with icon + labelTraffic-light backgrounds on every cell

Never

  • Two y-axes on one chart. Use two charts on a shared x-axis, or index both measures to 100.
  • 3D, shadows, gradients or decorative images inside a chart.
  • Rainbow colour scales, or a colour per bar when the bars are one series.
  • A legend you have to decode when four or fewer series could be labelled directly.
  • Gridlines darker than the data. Grid is --hl-grid, axis is --hl-axis, lines are 2 px, markers at least 8 px.

Do and don't

Tool themes

Power BI Desktop

  1. View → Themes → Browse for themes and open harborline-light.json (or harborline-dark.json).
  2. Apply a department background (see Layout).

The theme sets: the eight data colours in slot order; good, neutral and bad; the diverging scale (minimum, center, maximum) for conditional formatting; text classes; and default styles for every visual container (white card, 1 px border, radius 8, padding 12, no shadow), the page and filter pane, the new Card, the legacy Card, KPI, Table, Matrix and Slicer.

It cannot set: per-measure formats, conditional formatting rules, sort orders, or colours that a report author has already set by hand on a visual (reset those with Reset to default). Custom visuals from AppSource ignore most of it. In the Power BI service, viewers without the fonts see Segoe UI.

The theme was checked against the key names in Microsoft's report theme schema 2.159 (result). If you edit it, re-run python brand\validation\check_powerbi_theme.py brand\themes\powerbi\harborline-light.json.

Streamlit

Copy themes/streamlit/.streamlit next to your app's entry script. It defines both a light and a dark theme ([theme.light], [theme.dark]) that follow the viewer's system setting, loads the three fonts from Google Fonts, and sets the chart palettes. Streamlit ignores sequential and diverging lists that are not exactly ten colours, so those two are ten-step resamples of the brand ramps. Check your Streamlit release supports the mode sections with streamlit config show | findstr theme.light; on older releases keep only [theme].

Streamlit in Snowflake supports the [theme] and [theme.sidebar] sections only, with a smaller subset on the warehouse runtime. Use the light-only file; it falls back to the built-in sans serif.

Databricks AI/BI dashboards

Open a draft dashboard, click an empty part of the canvas, then Settings → Theme and customise. (A workspace admin can set it once for everyone under Settings → Appearance → AI/BI → Theme; existing dashboards keep their snapshot until an author re-applies it.)

Snowsight

Snowsight charts offer bar, line, scatter, heat grid and scorecard, with per-chart options in the Appearance panel. Snowflake documents no palette, font or background theming for them, so treat Snowsight as an analysis tool: check numbers there, and build the deliverable in Streamlit in Snowflake with the theme above, or in Power BI on top of Snowflake. If a Snowsight chart lets you set a series colour, take it from the categorical list in slot order.
